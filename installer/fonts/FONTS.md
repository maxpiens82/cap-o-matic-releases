# Fonts bundled with Cap-o-matic

The built-in presets use these fonts. The installer adds each one to Windows if that font isn't installed yet, and never removes them (projects keep using them). All are under the SIL Open Font License 1.1: each folder holds the font and its license, and the installer copies the licenses next to the plugin. They are unmodified, fixed-weight (non-variable) files, because Fusion's handling of variable fonts is untested.
